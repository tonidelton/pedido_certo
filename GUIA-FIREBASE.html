🔥 Configurar Firebase

Guia passo a passo para vincular o Firebase ao Pedido Certo

1 Criar conta no Firebase

Acesse o Firebase Console e faça login com sua conta Google:

Abrir Firebase Console →
Se você não tem conta Google, crie uma em accounts.google.com
2 Criar um novo projeto
  1. Clique em "Adicionar projeto" ou "Add project"
  2. Dê um nome ao projeto (ex: pedido-certo)
  3. Aceite os termos e clique em "Continuar"
  4. Desative o Google Analytics (opcional) e clique em "Criar projeto"
  5. Aguarde a criação do projeto (leva alguns segundos)
3 Ativar o Firestore Database
  1. No menu lateral esquerdo, clique em "Firestore Database" ou "Build > Firestore Database"
  2. Clique em "Criar banco de dados" ou "Create database"
  3. Selecione "Iniciar no modo de teste" (Start in test mode)
  4. Escolha a localização mais próxima (ex: southamerica-east1 para São Paulo)
  5. Clique em "Ativar" ou "Enable"
O modo de teste expira em 30 dias. Para produção, configure regras de segurança com autenticação.
4 Registrar o aplicativo Web
  1. Na página inicial do projeto, procure a seção "Comece adicionando o Firebase ao seu app"
  2. Clique no ícone Web () ou em "Adicionar app"
  3. Dê um apelido para o app (ex: pedido-certo-web)
  4. NÃO marque a opção "Firebase Hosting"
  5. Clique em "Registrar app" ou "Register app"
5 Copiar as credenciais

Após registrar o app, aparecerá um bloco de código como este:

const firebaseConfig = {
  apiKey: "AIzaSy...",
  authDomain: "pedido-certo.firebaseapp.com",
  projectId: "pedido-certo",
  storageBucket: "pedido-certo.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123456789:web:abc123"
};

Copie todos esses valores - você vai precisar deles no próximo passo!

6 Configurar o arquivo .env

Abra o arquivo .env na raiz do projeto e preencha com suas credenciais:

# Configuração do Firebase - Pedido Certo

VITE_FIREBASE_API_KEY=AIzaSy...
VITE_FIREBASE_AUTH_DOMAIN=pedido-certo.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=pedido-certo
VITE_FIREBASE_STORAGE_BUCKET=pedido-certo.appspot.com
VITE_FIREBASE_MESSAGING_SENDER_ID=123456789
VITE_FIREBASE_APP_ID=1:123456789:web:abc123
IMPORTANTE: Não compartilhe este arquivo! Ele contém suas credenciais secretas.
7 Reiniciar o servidor

Após salvar o arquivo .env, reinicie o servidor de desenvolvimento:

# Pare o servidor (Ctrl+C) e execute novamente:
npm run dev
Pronto! O app agora está conectado ao Firebase e os dados serão sincronizados na nuvem.
8 Verificar a configuração

Na tela inicial do app, clique no ícone do banco de dados (🗄️) para ver o status do Firebase:

  • Se aparecer "Firebase Configurado!" em verde, está tudo certo!
  • Se aparecer "Firebase Não Configurado" em amarelo, verifique o arquivo .env

🎉 Pronto!

Seu app agora está conectado ao Firebase! Os dados serão sincronizados em tempo real e você poderá acessar de qualquer dispositivo.

  • Fazer deploy na Vercel ou Netlify
